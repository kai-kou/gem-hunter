## 15 ステップ（順序どおりに進め、ゲートを飛ばさない）

```
【テキスト版フェーズ】
 1. スライド構成作成
 2. スライド構成セルフレビュー        ← MECE + ファクトチェック + 最新情報リサーチ（スキップ禁止）
 3. テキスト版スライド作成
 4. テキスト版スライドセルフレビュー    ← スキップ禁止
 5. Google スライドアップロード         ← 本リポジトリでは「リポジトリ内配置 + PR」に読み替え
 6. テキスト版のユーザーレビュー依頼    ← 明示的承認を得るまで停止
 7. ユーザーフィードバック反映
 8. テキスト版最終セルフレビュー        ← スキップ禁止
【画像版フェーズ】
 9. 画像版スライド作成                  ← プロンプトに「一字一句正確に」を必ず含める
10. 画像版スライドセルフレビュー        ← スキップ禁止
11. アップロード                        ← 同上の読み替え
12. 画像版のユーザーレビュー依頼        ← 明示的承認を得るまで停止
13. ユーザーフィードバック反映
14. 画像版最終セルフレビュー            ← スキップ禁止
15. 最終版アップロード
```

🔴 **同時に作らない。** マークダウン → テキスト版 → 画像版の順で、各ゲート（Step 2/4/6/8/10/12/14）を
通してから次のフェーズへ進む。

## 必達原則（全ステップ共通・絶対遵守）

1. セルフレビューをスキップしない（Step 2 / 4 / 8 / 10 / 14。指摘ゼロでも「指摘なし」と記録）
2. MECE 観点のレビューを必ず含める（`doc-review` の軸 2 が該当）
3. 不明点・曖昧な点は推測せず質問する
4. ファクトチェックを徹底する（裏取りできない主張は載せない、または「要確認」と明示）
5. 常に最新情報をリサーチして事実確認する（出典 URL・取得日をレビュー記録に残す）
6. ユーザーレビューは明示的な承認を得るまで次へ進まない（沈黙・曖昧な返答を承認とみなさない）
7. 各スライドは「見ただけで伝えたいことが分かる」テキスト量にする
8. 画像生成時は「一字一句正確に（VERBATIM）」を必ず指示する
