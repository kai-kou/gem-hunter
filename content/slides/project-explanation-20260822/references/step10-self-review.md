## チェック項目（全 19 枚で実施）

- [x] **テキスト完全性（一字一句）**: 構成の見出し・本文が全て、省略・言い換えなしで画像内にある
- [x] **重複**: 同じテキストが 2 回以上表示されていない
- [x] **文字正確性**: 漢字の欠落・文字化け・不完全な単語・ルビがない
- [x] **追加テキスト**: 構成にないテキスト（数字・キャプション・装飾ラベル）が足されていない
- [x] **レイアウト**: 文字が潰れず読めるサイズで配置されている
- [x] **MECE**: 画像版全体で論点の漏れ・重複がない（テキスト版と同一構成のため Step 2 の結果を継承）
- [x] **デザイン統一**: 新規 12 枚と既存 5 枚でパレット（ネイビー / ティール / コーラル / マスタード + 生成りの紙地）・グラレコ調・帯見出しが揃っている
