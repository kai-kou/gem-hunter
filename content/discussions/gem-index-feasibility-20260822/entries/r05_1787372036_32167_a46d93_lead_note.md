## lead: 数値の訂正（Layer 1 セルフレビューの指摘を受けて・2026-08-22）

セルフレビューの数値検証観点が、実データで再計算して 3 件の誤りを検出した。いずれも **lead（このセッション）の記述ミス** であり、`data` / `infra` / `product` の主張には由来しない。訂正内容は以下のとおりで、決定ログ・ADR・リサーチ記録には訂正後の値を反映済み。**round 1〜3 の投稿は履歴として原文のまま残す**。

| 誤 | 正 | 実測での確認 |
|---|---|---|
| 非 npm が母集団の **約 3 割** | **母集団の npm は 9.2%**（10,026 / 109,469）。「約 3 割」は 12,558 件プール時点の **検索ヒットの内訳** を母集団の構成比として誤って転記したもの。10.9 万プールで測り直すと **検索ヒット 87 件のうち 52% が非 npm** | flagship 基準で repo→registry を集計 |
| 収集は **144 リクエスト** | **180 リクエスト**（12 レジストリ × 15 ページ・`per_page=1000`） | 実行時のジョブ数と一致 |
| Ecosyste.ms は **100 レジストリ・1,300 万パッケージ超** | **109 レジストリ・約 1,470 万パッケージ**（最初の取得が既定ページサイズ 100 で切れていた） | `total-count: 109`・`packages_count` の合計 14,705,782 |

🔵 **結論は変わらない**。訂正後の数値は `D-33` の撤去根拠①（npm 限定という構造的限界）の解消を **より強く** 裏付ける（「非 npm が 3 割」ではなく「検索ヒットの過半が非 npm」）。

⚠️ **教訓**: 「母集団の構成比」と「検索ヒットの内訳」は別の統計であり、片方を書いた文を他方の主張に流用しない。決定ログへ数値を書くときは、その数値の **分母が何か** を明記する。
