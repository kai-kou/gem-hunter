- **受け入れ範囲**: `ADR 0009`（Hidden Gem スコア定義）**のみ**を選択肢Aの粒度（背景+却下案+ADRリンク）で「設計上の判断」節に追加することを支持する。理由: 3読者のうち最優先の「レビュアー」が求める“工夫点”の代表例として最も説得力が強く（プロダクトの中核差別化要素であり、LP 側でも `site/index.html` の主要訴求として使われている＝読者にとって既知の文脈と接続しやすい）、1件追加なら分量への影響が読める。
