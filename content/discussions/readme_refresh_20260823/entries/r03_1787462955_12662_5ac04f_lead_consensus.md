### 対立が残り、lead が決着させた点

#### 対立 1: ADR 0014（今日の Gem）の扱い

- **req_gate**（`[major]`・維持）: 他 6 項目と同格の独立節として昇格せよ。冒頭で最初に紹介する目玉機能なのに「なぜ有限件数か」「なぜ無限フィード・通知を採らなかったか」が本文にない。
- **fact_check**: ADR 0014 の骨子（有限 5 件・無限フィード不採用・日付を唯一のシードとする決定論的生成）は **README 本文のどこにも実質的に書かれていない**と事実確認し、req_gate の前提を支持。
- **reader_flow**（条件付き反対）: 228 行に他項目と同格のフルサイズ小節（10〜15 行）を足すのは読者負荷が大きい。既存の Hidden Gem 節へ 2〜3 行の追記で代替せよ。

**lead の決着**: 両者の妥当な部分を採る。**独立節は作るが、req_gate が求めた「ADR 0014 単独のフルサイズ節」ではなく、ADR 0014 と ADR 0008 を 1 つの判断としてまとめた短い節を新設する**。

- 根拠: ADR 0014 自身が frontmatter の関連に [ADR 0008](0008-pagination-over-infinite-scroll.md) を「無限スクロール不採用の既存決定」として挙げており、**「無限に流さず有限で区切る」という同一の設計思想の 2 つの現れ**である。別々の節にすると重複し、まとめれば 1 節で 2 つの ADR を可視化できる。
- これは req_gate が round 1 で `[minor]`（余裕があれば）とした ADR 0008 の昇格要求も同時に満たす。reader_flow も ADR 0008 について「独立節ではなく短い追記に留めることを推奨」としており、1 節への同居はこの推奨とも矛盾しない。
- reader_flow の読者負荷への懸念には、下記の対立 2（重複削除）でネットの増分を抑えることで応える。

#### 対立 2: Gem Index 母集団の記述の重複

- **req_gate**（`[major]`・維持）: Hidden Gem 節と Gem Index 節が「約 11 万 → 汚染フィルタ + repo 単位 dedupe → 62,483」という同一の算出根拠をほぼ同じ言葉で二重に書いている。将来 `D-36` / `D-37` の値が更新されたとき片方だけ直されて desync する。
- **fact_check**（部分同意）: 重複は **該当 1〜2 文（62,483 の算出根拠を繰り返す部分）に限って事実**。新設節にしかない情報（レジストリ別成層化・既定 15,000 件の固定枠・シャード配信 + isolate 内キャッシュ + singleton promise）が過半を占め、Hidden Gem 節は「指標の意味と適用先」、新設節は「母集団の作り方と配信方式」という **役割の分担は成立している**。
- **reader_flow**: 統合には賛成（縦の情報量が減る）。

**lead の決着**: **fact_check の切り分けを採る**。節そのものの統合（req_gate が求めた「シャード配信を ADR 参照 1 行へ格下げ」）は行わない — 役割が分かれていることを fact_check が確認しており、格下げすると `NFR-30` が求める工夫点の記録が薄くなる。**重複しているのは 62,483 の算出根拠を繰り返す 1 文だけなので、新設節側のその 1 文を削り、Hidden Gem 節に一本化する**。desync リスクは消え、新設節の主張（成層化・固定枠・配信方式）は失われない（fact_check が「置き換えても失われない」と明言）。

#### 対立 3: `minimum-requirements-checklist.md` の陳腐化

- **scope_guard**（out_of_scope・維持）: 陳腐化は最低 4 箇所（`.github/workflows/` の存在有無・チェック本数「全 20」・設計上の判断が旧 2 項目・環境変数「8 変数」）に及び、実質的な書き直しが要る。対象ファイルは PR スコープの明示リストに含まれない。

- **fact_check**: `ls .github/workflows/` を実行して実在を確認し、スコープ外判定に同意。

**lead の決着**: **out_of_scope を採る**（3 レンズが独立に同結論）。ADR 0004 の 1 行追記とは性質が違う — あちらは README 本文が書き換えた事実の裏返しで 1 行、こちらは 4 箇所の書き直しでスコープ外のファイル。**別 Issue を起票する**。
